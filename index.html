Endpoints de Alta Velocidade Cloudflare Edge

        
Consuma a API em microssegundos direto da borda Anycast sem dependências externas.


        
1. Decodificar e Validar Pix

        
POST /api/pix/decodificar ou GET /api/pix/decodificar?codigo=000201...

        
curl -X POST "https://pixvalidator-pro-api.pixvalidator.workers.dev/api/pix/decodificar" \
  -H "Content-Type: application/json" \
  -d '{"codigo": "00020101021126670014br.gov.bcb.pix0117clepta2@gmail.com520400005303986540549.905802BR5911CLEPTA TECH6009SAO PAULO62140510PEDIDO982163045E7A"}'


        
2. Gerar Código Pix Copia e Cola Oficial

        
POST /api/pix/gerar ou GET /api/pix/gerar?chave=...&nome=...&valor=...

        
curl -X POST "https://pixvalidator-pro-api.pixvalidator.workers.dev/api/pix/gerar" \
  -H "Content-Type: application/json" \
  -d '{
    "chave": "clepta2@gmail.com",
    "nome": "MINHA EMPRESA",
    "cidade": "SAO PAULO",
    "valor": 120.00,
    "txid": "PEDIDO9912"
  }'


        
3. Validar Chave Pix Isolada

        
GET /api/pix/chave?chave=52998224725

        
curl -X GET "https://pixvalidator-pro-api.pixvalidator.workers.dev/api/pix/chave?chave=+5511987654321"
